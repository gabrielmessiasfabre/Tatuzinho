# 🐢 Tatuzinho — Bot Discord completo

Bot em Python com mais de 100 comandos `/` em português.

## Recursos
- Moderação
- Administração
- Usuários e servidor
- Economia com SQLite
- XP e níveis
- Diversão
- Tickets
- Sugestões
- Enquetes
- Sorteios
- Boas-vindas/saídas
- Logs
- Configurações
- Utilidades

## Instalação

```bash
pip install -r requirements.txt
```

Copie `.env.example` para `.env` e coloque o token do bot.

```bash
python bot.py
```

Nunca publique o `.env` no GitHub.

## Permissões
Convide o bot com `bot` e `applications.commands`. Dê somente as permissões necessárias ao servidor.
